Flowforge MCP

เชื่อม MCP client เข้ากับ Flowforge แล้วใช้ Jira account ของคุณเอง

MCP URL สำหรับ Cursor และ client ทั่วไป
https://flowforge-mobilewright.chawapon-rr.chatgpt.site/api/mcp
OAuth 2.1 + PKCE Jira read-only

เริ่มใช้งาน

  1. เพิ่ม URL ด้านบนใน MCP client
  2. client จะเปิด OAuth discovery และ Dynamic Client Registration
  3. Login ที่ Atlassian/Jira และอนุญาต read-only
  4. หลังเชื่อมต่อแล้วเรียก tools ได้

Tools

  • connect_jira — เชื่อม Jira account ของผู้ใช้
  • load_jira_ticket — โหลด Jira ticket, AC, comments และ attachments
  • parse_gwt — แปลงเป็น Given / When / Then
  • generate_test_script — สร้าง Mobilewright script
  • format_jira_gwt — สร้าง Jira wiki และ HTML table
  • business_to_qa_detail — แปลง Business Expectation/GWT เป็น QA Execution Detail ภาษาไทยแบบละเอียด พร้อม precondition, test data, steps, expected result, evidence, edge case และ open questions

เอกสาร public

หน้านี้เปิดอ่านได้โดยไม่ต้อง Login ส่วน endpoint MCP เท่านั้นที่ต้อง OAuth
