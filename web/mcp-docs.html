1) Cloud MCP — Cursor / client ทั่วไป
https://flowforge-mobilewright.chawapon-rr.chatgpt.site/api/mcp

2) Local MCP — Simulator a11y / path scan

เริ่มใช้งาน (cloud)

  1. เพิ่ม Cloud MCP URL ใน Cursor
  2. OAuth / Login Jira read-only
  3. เรียก tools ด้านล่างได้
  4. ถ้าต้องการ scan sim → เพิ่ม local MCP ตามกล่องด้านบน แล้ว restart จน ready

Cloud tools

  • connect_jira — เชื่อม Jira account
  • load_jira_ticket — โหลด ticket / AC / comments / attachments
  • parse_gwt — แปลงเป็น Given / When / Then
  • generate_test_script — สร้าง Mobilewright draft
  • format_jira_gwt — Jira wiki / HTML table
  • business_to_qa_detail — QA execution detail ภาษาไทย
  • get_sim_scan_setup — วิธีเปิด Simulator scan (local MCP)
  • prepare_local_gen — สร้าง handoff (tool + arguments) ให้ไปเรียก local gen เขียน tests/generated_mcp/

Pipeline ที่แนะนำ

  1. Cloud: load_jira_ticket → parse_gwt
  2. Cloud (optional): generate_test_script ได้แค่ draft
  3. Cloud: prepare_local_gen ด้วย scenarios (+ draft ถ้ามี)
  4. Local: เรียก nextLocalCall.tool ตาม handoff บน flowforge-local-sim

Local tools (หลังติดตั้ง flowforge-local-sim)

  • scan_accessibility_ids — dump a11y ของจอ Simulator ปัจจุบัน
  • explore_sim_paths — เดิน tab / scroll / re-tap
  • generate_helpers_from_a11y — สร้าง share helpers ที่ยังขาด
  • generate_test_script / enrich_flowforge_script — gen โดย reuse share ก่อน scan เมื่อติด
