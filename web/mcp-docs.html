Flowforge MCP

เชื่อม MCP client เข้ากับ Flowforge แล้วใช้ Jira account ของคุณเองเพื่อโหลด ticket และสร้าง Mobilewright test script

MCP URL
https://flowforge-mobilewright.chawapon-rr.chatgpt.site/mcp
OAuth 2.1 + PKCE Jira read-only

เริ่มใช้งาน

  1. เพิ่ม MCP server URL ด้านบนใน MCP client ที่รองรับ Streamable HTTP
  2. เมื่อ client ขอสิทธิ์ ให้กด Login with Jira
  3. เลือก Jira workspace และอนุญาตสิทธิ์แบบ read-only
  4. กลับไปที่ MCP client แล้วเรียกใช้ tools ได้

Tools

  • load_jira_ticket — โหลด Jira ticket, description, AC, comments และ attachments
  • parse_gwt — แปลงข้อความเป็น Given / When / Then
  • generate_test_script — สร้าง Mobilewright script
  • format_jira_gwt — สร้าง Jira wiki และ HTML table

ตัวอย่างคำสั่ง

โหลด Jira ticket VAL-1928 แล้วสรุป test cases ให้ฉัน
จาก ticket VAL-1928 ช่วยสร้าง Mobilewright test script
แปลง acceptance criteria นี้เป็น GWT และตรวจว่ามี draft case หรือไม่

สิทธิ์และความปลอดภัย

แต่ละคนเชื่อมต่อ Jira account ของตัวเอง ระบบจะใช้เฉพาะสิทธิ์อ่านข้อมูล Jira และไม่ส่ง Jira access token ให้ MCP client โดยตรง

สำหรับผู้พัฒนา

GET /.well-known/oauth-protected-resource/mcp
GET /.well-known/oauth-authorization-server
POST /mcp
